PENTING:
GitHub Pages adalah hosting statis. Prototype admin ini memakai localStorage, jadi perubahan hanya tersimpan pada browser/perangkat yang digunakan.
Untuk admin online yang benar-benar bisa:
1. login,
2. mengubah link,
3. upload PDF brosur,
4. menyimpan perubahan untuk semua pengunjung,

gunakan GitHub Pages sebagai frontend + backend/storage gratis (mis. Supabase/Firebase). Jangan menaruh GitHub Personal Access Token di JavaScript publik.

Struktur produksi yang disarankan:
GitHub Pages -> halaman publik + admin
Supabase/Firebase -> autentikasi + database + storage PDF
